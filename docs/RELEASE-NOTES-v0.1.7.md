## v0.1.7 — 属性页两项 bug 修复

1. **切换角色后数值不刷新**（需退出重进才变）：根因是属性/五官页在列表行内部直接读 `StateFlow.value`，
   该读取不被 Compose 快照跟踪，切换角色不触发重组。现改为在页面 body（已订阅 state）统一取值后按参数下发，
   切换角色立即刷新（属性页与五官页、颜色块一并修复）。
2. **四个数值标注不清**：
   - 字段名改为「寿元·当前 / 寿元·上限 / 灵气·当前 / 武力·当前」，每行附说明（对应游戏面板「寿元 10/60」斜杠前/后的数）；
   - 行内高亮显示「游戏内数值：X」；
   - 角色选择器中的裸「提示值」改为带标签摘要：`寿元 x/y · 灵气 a · 武力 b`，方便对照游戏确认角色。

其余沿用 v0.1.6（校准偏移、写回安全管线、占位符签名自动发布）。
