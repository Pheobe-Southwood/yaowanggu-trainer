# ADR-0004 v1 范围：脸 + 核心属性，暂不支持灵石

## 状态

已接受

## 背景

用户要求：必须实现五官外貌修改；灵石、寿元等为加分项。
灵石不在角色 39 项字段表内（教程根本没有货币字段）——它属于全局货币数据
（大概率在另一段全局存档中），且贸然改货币会破坏游戏经济，风险高于收益。

## 决策

v1：

- 必做：20 项外观字段（含 HSV 颜色、幼态发型）+ 20 项字段的编号参考图。
- 加分：角色 39 项中的核心字段（寿元、生日、性别、境界、灵根、灵气、武力…），
  高级字段在「属性」页，未知字段折叠并标注风险。
- 明确不做：灵石/灵玉；兽耳代码（随妖族身份字段 9 走，参考图内置）。

后续若全局存档被定位，再考虑灵石。

## 后果

- UI 以「五官」为主导航，属性为次级页。
- 参考图必须内嵌（编号在游戏内无文字说明）。
