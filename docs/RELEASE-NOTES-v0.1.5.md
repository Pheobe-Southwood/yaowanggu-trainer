## v0.1.5 — 颜色预览修正 + 写回防事故 + 签名发布

### 1. 颜色预览贴近游戏实际
- 实证社区色表（13 组 `色相;饱和;明暗` → 游戏内实际发色）：游戏色相 = 标准色相的**镜像**（360−h），饱和/明暗按 **200 归一**（200 即满，400 钳制）。旧预览用原色相 + /400，色相与明度双错。
- 修复肤色色块误用**发色**饱和/明暗的 bug（肤色差别大的直接原因）；肤色基色相固定 25°。
- 色块加描边（深色模式可见）并显示 `#RRGGBB`，便于与游戏截图核对。

### 2. 写回防事故（针对「改完进游戏检测不到存档」）
- **游戏运行中禁止写回**（硬阻断，明确提示先完全退出游戏）——运行中互踩会产生截断模块，正是本次事故的推断根因。
- **原子写**：tmp 文件 → 回读字节自检 → 容器语义自检 → `mv` 原子改名 → 最终回读验证；任一步失败即中止，原文件不受影响。
- **备份移出游戏目录**：`/sdcard/yaowanggu-trainer/backup/`，游戏目录不再出现任何非游戏文件。
- 游戏目录残留文件（旧 `.bak`/tmp）检测 + 一键「清理残留」。
- 首页新增「恢复此备份」一键回滚。
- 诊断包追加：备份目录/最近备份、残留文件列表；写回全流程逐步入日志。

### 3. 签名与发布
- release APK 现由仓库内**占位符 keystore**（`keystore/release-placeholder.jks`）签名，历次构建签名一致、可覆盖升级；CI 用 apksigner 校验。
- 打 `v*` tag 时 GitHub Actions 自动创建 Release 并上传 debug + release 两个 APK。

### 使用提示
- 写回前务必**完全退出游戏**（后台杀掉），否则 App 会拒绝写回并提示。
- 颜色预览为映射近似；若某色仍与游戏内不符，把游戏截图 + 当前 `#RRGGBB` 发我即可校准。
- 本版本 release APK 为占位符签名，仅用于真机测试分发。
