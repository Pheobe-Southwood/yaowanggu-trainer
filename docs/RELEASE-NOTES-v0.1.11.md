# v0.1.11 — 更多可改字段（灵根/境界/生日…）+ 角色命名与武力搜索 + UI 精简

依据 2026-10-02 诊断包与 4 张游戏面板截图逐 chip 对照校准（党允文/居植/于至行/弘元）。

## 新增可编辑字段（属性页「进阶属性」「灵根」卡）
- **灵根**：八旗（金水木火土冰风雷）开关 + 总纲下拉；灵根文案实时预览（单灵根=「X变异天灵根」，与面板一致）。
- **境界 / 阶段**：下拉选择（阶段选项随境界：金丹以上 前/中/后/大圆满，炼气/筑基 1-10 层，凡人不可改）。
- **生日 月/日、性别、所在地、门派、种族(兽耳)**：均可写；所在地/门派为数值+已知值提示（2=药王谷 4=万剑山 7=大自在殿）。
- 原有 寿元/灵气/武力 编辑不变（灵气 ×100 定点自动换算）。

## 校准修正
- **寿元上限改为随 (境界, 阶段) 派生**：金丹大圆满 300、合体中期 3000、合体大圆满 3500、大乘前期 5000、凡人 60、炼气 100；
  灵气上限补 合体 100400、大乘 220800。**v0.1.10 的「金丹 280」作废**（面板实为 300）。未验证组合显示 —，不臆造。
- **删除「突破几率」行**：实测 face−10 与面板不符（106/81/190/180 vs 9/9/35/13），突破几率/渡劫死亡率为游戏侧计算值，存档不存储。

## 角色查找
- **命名**：选择器「命名」给任意角色起别名（存本机，不写存档），别名显示在选择器与属性页标题。
- **搜索**：选择器搜索框支持 别名 / 角色 ID / 武力值 子串匹配（如输入 175100 直接定位党允文），命中列表点击即切换。

## UI 精简
- 属性页/选择器删除全部说明性长段文字与「记录 #·长度」等技术行；只保留数据与操作。
- 首页模块说明压缩为一句话。

## 其他
- 诊断包 charFields 行增补 gender/location/sect/race/rootType/rootFlags，便于后续校准。
- 写回安全协议不变：游戏运行中硬阻断、自动备份、原子写+回读验证。
