## v0.1.6 — 寿元/灵气/武力 修改生效 + 显示与游戏一致

### 修复「修改寿元不生效、显示数量与游戏不符」
根因：属性页此前绑定通用扫描猜出的错误窗口。本轮用你导出的诊断包 + 属性面板截图完成真机校准：
- **寿元当前/上限 = 五官窗口前第 63/62 个整数**（`(10,60,0,角色ID)` 模式，新旧存档 6+ 记录验证）；
- **灵气/武力 = 五官窗口前第 20/19 个整数**（旧档百万级大数对同位；你的主角 0/1 与面板一致）。
属性页现在只显示并允许修改这 4 个已校准字段，数值与游戏面板一致；写回走既有安全管线（zlib 重压缩 + 原子写 + 回读验证）。

### 未开放字段（防写坏）
灵玉（灵石）、境界、突破几率、灵根、出生年月、所在地/门派等本轮无法唯一定位 → 属性页明确标注「未映射」且不可编辑；下一轮用带时间差的双诊断包差分分析补齐。

### 其它
- 角色选择器移到五官/属性两页共用；属性页顶部显示当前角色 ID 与记录位置。
- 沿用 v0.1.5 的写回防事故与占位符签名；tag 自动发布 Release。

### 使用
1. 完全退出游戏 → 打开 App → 刷新（自动打开外观模块）。
2. 「属性」页确认角色（ID/提示值对照游戏）→ 改寿元/灵气/武力 → 写回 → 重开游戏验证。
3. 若数值与面板不符：诊断页导出 zip + 面板截图发我。
