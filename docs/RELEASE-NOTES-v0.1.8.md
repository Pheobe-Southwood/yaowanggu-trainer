## v0.1.8 — 「显示 0 而非 10」与「说明看不到」修复

### 1. 寿元前数显示 0（上限却对）
根因：属性页默认选中**角色 ID 1**——一个年龄 0 的凡人 NPC，其寿元上限同样是 60、灵气/武力也是 0/1，与主角面板高度相似，极易误认；主角实际是另一条记录（校准包中为 ID 146，年龄 10/上限 60）。
修复：
- 新增**「标记为主角」**：在角色选择器里切到你的主角（对照 寿元/灵气/武力 与游戏面板）点一次标记，charId 持久化保存；之后每次打开存档**自动选中主角**，选择器中显示 ★主角。
- 未标记时以红字提示「当前默认 ID 1 可能是 NPC」。
- 字段改名对齐面板写法：「寿元 10/60 的前数（年龄/当前）」「寿元 10/60 的后数（上限）」等，杜绝歧义。

### 2. 说明文字看不到
属性行改为上下结构：字段名 + 说明（全宽、bodyMedium）在上，「游戏内：X」与 ±10/输入/写入修改在下；说明必然位于数字上方且不再被控件挤压。
